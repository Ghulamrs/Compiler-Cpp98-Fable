Fixed on 2026-10-14 (lanes V, A, L; verified: suite, selfhost generation two, suite under the self-built compiler, cprog, matrix, eh, mix):
T() value-initialisation zeroes as cl; a float passed to printf or any variadic function is promoted to double;
catch (Base*) matches a thrown Derived* with the pointer adjusted; replaced global operator new/delete are called;
delete[] of a cookie-less class uses its own operator delete[]; multicharacter constants ('ab') and "\x41" "b" as cl;
floating constants cast to integers folded as cl, in code and in static initialisers; the halfway float literal is
correctly rounded; member-pointer sizes of a class completed later; the old pipeline no longer overflows its stack on
a folder that holds a class named T.
